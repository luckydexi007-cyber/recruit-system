# 车辆与交通学院·团总支学生会 招新系统（云端同步版）

本版本新增了**后端服务 + 云端数据库**，实现了跨设备、跨网络的实时数据同步：
学生在任何设备/网络下注册、投递，管理员在后台都能实时看到。

## 一、目录结构

```
recruit/
├── 启动服务.bat       # Windows 一键启动（推荐，双击即可）
├── server.js          # 后端服务（零依赖，仅用 Node 内置模块）
├── data.json          # 数据库文件（首次运行自动生成，所有数据都在这里）
├── public/
│   └── index.html     # 前端页面（自动调用后端接口）
└── README.md          # 本说明
```

## 二、运行环境

只需要安装 **Node.js**（版本 16 及以上即可），无需安装任何额外依赖。

- 检查是否已安装：命令行输入 `node -v`，能显示版本号即可。
- 未安装：前往 https://nodejs.org 下载 LTS 版本安装。

## 三、启动服务（最简单的方式）

**直接双击 `启动服务.bat`**，会自动弹出窗口并显示：
- 电脑上访问的地址：`http://localhost:3000`
- 手机访问的地址：`http://你的电脑IP:3000`

然后在浏览器打开对应地址即可。

> 也可以手动启动：在本文件夹打开命令行，执行 `node server.js`。

## 四、手机与电脑如何「实时同步」

**核心原理：数据不在手机里，也不在浏览器里，而是集中存在运行 `server.js` 的这台电脑上。**
只要手机和电脑访问的是**同一个服务地址**，看到的就永远是同一份实时数据。

### 步骤

1. 电脑上双击 `启动服务.bat`（或运行 `node server.js`），保持窗口不关闭。
2. 记下窗口里显示的「手机访问地址」，形如 `http://192.168.1.5:3000`。
3. 让**手机和电脑连同一个 WiFi**。
4. 手机浏览器输入那个地址 → 打开的就是同一个招新系统。

### 效果

- 手机注册/投递 → 电脑管理员后台**立即**刷新就能看到；
- 电脑管理员录取/调剂 → 手机用户中心**自动刷新**（每 4 秒）即显示"恭喜你已被 XX 部录取"。

> ⚠️ 注意：`localhost` 永远只代表「当前这台设备自己」。
> 所以手机上必须用**电脑的局域网 IP**（如 `192.168.x.x`），不能用 `localhost`。

### 查看电脑 IP 的方法

命令行输入 `ipconfig`，找到 **IPv4 地址**（一般是 `192.168.x.x` 或 `172.16.x.x`）。

## 五、让所有人都能访问（公网正式上线）

上面是局域网方案（同一 WiFi 内可用）。如果希望**任何人、任何网络**都能访问，把整个 `recruit` 文件夹部署到云端：

- **Render**（render.com）：新建 Web Service，Start Command 填 `node server.js`
- **Railway**（railway.app）：上传代码，自动识别 Node 项目
- **阿里云 / 腾讯云轻量服务器**：上传文件后运行 `node server.js`，放行 3000 端口

部署后会得到一个公网网址（如 `https://xxx.onrender.com`），发给谁都能用，数据全局实时同步。

> 修改终端管理员账号密码：启动前设置环境变量即可：
> ```bash
> TERMINAL_USER=你的账号 TERMINAL_PASS=你的密码 node server.js
> ```

## 六、功能清单

| 角色 | 功能 |
|------|------|
| 游客 | 浏览首页、六大部门介绍、注册、登录 |

## 七、数据与安全说明

- 所有账号、简历、附件（Base64 内嵌）均保存在服务端的 `data.json` 中；
  备份系统只需复制该文件。
- 用户密码使用 **PBKDF2-SHA512（10 万次迭代 + 随机盐）** 加盐哈希存储，
  数据库中不保存明文密码，接口也不会把密码下发到浏览器。
- 登录采用服务端签发的 **随机 Token 会话**，权限在后端校验（用户/管理员/终端管理员分级）。

## 八、常见问题

**Q：网页显示 404 Not Found？**
A：说明 `public/index.html` 不在 `server.js` 同级目录下。请确保 `index.html` 位于 `server.js` 旁边名为 `public` 的文件夹里。

**Q：手机打不开，电脑却正常？**
A：① 手机必须用电脑的 IP（如 `192.168.x.x:3000`）而不是 `localhost`；
   ② 确认手机与电脑连同一个 WiFi；
   ③ Windows 防火墙首次会弹窗，需点"允许访问"。

**Q：端口被占用怎么办？**
A：用其它端口启动，例如 `set PORT=8080 && node server.js`（Windows）。

**Q：想清空所有数据重新开始？**
A：停止服务，删除 `data.json`，再重新启动即可。
